# EDA и прогноз выручки: Online Retail II

Учебно-показательный проект: разведочный анализ, очистка «грязной» выгрузки интернет-магазина и модель прогноза выручки. Всё в одном ноутбуке — так же, как в формате заказа на Kwork «анализ данных и обучение модели».

## Датасет

[Online Retail II](https://archive.ics.uci.edu/dataset/502/online+retail+ii) (UCI ML Repository) — транзакции британского интернет-магазина за 2009–2011 годы: 1 067 371 строка, 8 колонок.

В репозитории лежит выборка на 100 000 строк (`data/raw/online_retail_ii_sample.csv`, seed 42). Полный файл `data/raw/online_retail_ii.csv` (112 МБ) не коммитится — он собирается скриптом из исходного xlsx.

Данные намеренно грязные: отмены с отрицательным количеством, нулевые цены, пропущенные `Customer ID`, дубликаты строк, товары с описанием без цены. Именно это и показывается в ноутбуке.

## Структура

## Запуск

```bash
python -m pip install -r requirements.txt
jupyter notebook notebooks/01_eda_model.ipynb
```

Ноутбук читает `data/raw/online_retail_ii.csv`, если он есть, иначе выборку. Все пути относительные — запускать из корня проекта.

## Что внутри ноутбука

1. Профиль данных: типы, пропуски, дубликаты, отрицательные количества.
2. Очистка: отмены, возвраты, нулевые цены, пропущенные клиенты.
3. EDA: выручка по месяцам, топ товаров и стран, распределение заказов.
4. Признаки: категориальные день недели и месяц, числовые лаги и скользящее среднее.
5. Проверка утечек: хронология train/test, отсутствие `Revenue` в признаках, корректность лагов, отсутствие пропусков.
6. `Pipeline` + `ColumnTransformer`: `OneHotEncoder` для категорий, `StandardScaler` для чисел; сравнение четырёх вариантов по MAE/RMSE/MAPE/R².
7. Сохранение пайплайна целиком и выводы.

## Результаты

Прогон на выборке 100 000 строк, последние 120 дней — тест:

| Вариант | MAE, £ | RMSE, £ | MAPE | R² |
| --- | --- | --- | --- | --- |
| Baseline (вчерашний день) | 1 571,69 | 2 035,76 | 59,4% | −0,513 |
| OHE + StandardScaler | 1 187,07 | 1 526,88 | 44,8% | 0,149 |
| OHE без скейлера | 1 187,07 | 1 526,88 | 44,8% | 0,149 |
| Только числовые + скейлер | 1 252,37 | 1 602,01 | 43,7% | 0,063 |

Лучший вариант — `OneHotEncoder` + `StandardScaler`: MAE ниже baseline на 24,5%. Масштабирование числовых признаков на бустинге результат не меняет (деревья инвариантны к масштабу) — это видно по совпадению метрик `ohe_scaler` и `ohe_raw`. Категории важнее: без них MAE хуже на 65 £.

R² у baseline отрицательный: наивный прогноз хуже константы, потому что тестовый период — сезонный спад. Метрики, предсказания и пайплайн — в `outputs/` и `models/pipeline.pkl`.
